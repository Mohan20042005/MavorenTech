# SEO and local SEO plan

- One unique title, description and canonical per route (`pageMetadata`). JSON-LD only with facts that exist (no ratings, reviews or address).
- Routes: home, services (+12 service pages), portfolio (+6 case studies), pricing, offers, plan, process, blog (+posts), FAQ, contact, terms, privacy, 404. Refund page only after the owner supplies terms.
- Local SEO: target Tamil Nadu. Mention Erode, Chennai and Palladam only where real projects exist (Taj Restaurant, Studio 36 Photography, Deliz Saki, Our Oven Story, Fab Café). Do not invent an office address or a Google Business Profile.
- Keyword themes (natural use, no stuffing): website development in Tamil Nadu, business website development, restaurant website design, e-commerce website development, portfolio website development, affordable website development.
- After deploy: submit `/sitemap.xml` in Google Search Console, enable GA4 behind a consent banner, track WhatsApp clicks, promo code applications and enquiry submissions as events.
